# Cadence

Cadence is a daily puzzle platform featuring multiple games, inspired by
the daily-game format of platforms such as NYT Games.

## Current Games

- PixAlbum — identify albums from progressively revealed artwork

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- FastAPI
- Python

### Infrastructure
- PostgreSQL
- Redis
- Docker
